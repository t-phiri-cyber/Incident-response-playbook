\# Phishing Incident Simulation – PHISH-001



\## Incident Summary



An employee at Northstar Financial Services received a fraudulent Microsoft 365 account suspension email.



The employee clicked the embedded URL and entered their corporate credentials.



Subsequently, an unfamiliar IP address successfully authenticated to the employee's account. An unexpected mailbox forwarding rule was also created.



No confirmed data exfiltration has been identified.



\## Initial Evidence



| Evidence | Observation |

|---|---|

| Email | Fraudulent Microsoft 365 impersonation |

| User interaction | Link clicked |

| Credentials | Corporate credentials entered |

| Authentication | Successful login from unfamiliar IP |

| Mailbox | Unexpected forwarding rule |

| Data exfiltration | Not confirmed |
