# Incident Response Playbook



## Project Overview



The Incident Response Playbook is a cybersecurity documentation project designed to establish structured procedures for identifying, assessing, containing, investigating and recovering from common security incidents.



### Project Objectives



- Establish incident severity classifications.

- Develop response procedures for phishing attacks.

- Develop procedures for compromised accounts.

- Establish malware incident response procedures.

- Develop suspected data breach response procedures.

- Document evidence preservation and recovery processes.

- Conduct simulated incident response exercises.



## Incident Severity Classification



| Severity | Classification | Description |

|---|---|---|

| SEV 1 | Critical | Major security incident involving widespread compromise, ransomware or significant disruption to critical systems. |

| SEV 2 | High | Confirmed compromise involving accounts, endpoints or sensitive systems. |

| SEV 3 | Medium | Suspicious activity requiring investigation but with limited confirmed impact. |

| SEV 4 | Low | Low-impact or blocked security events with no confirmed compromise. |



## Incident Response Lifecycle



1. Identification

2. Triage and assessment

3. Containment

4. Eradication

5. Recovery

6. Post-incident review
